# HTML to Markdown 转换器

一个简单而强大的 HTML 到 Markdown 转换工具，基于 Nuxt 3 和 Turndown 构建。

## 在线示例

访问在线演示(国内): [https://html2md.dooo.fun/](https://html2md.dooo.fun/)
访问在线演示: [html2md.vercel.app](https://html2md.vercel.app)

## 功能特点

- 实时转换 HTML 到 Markdown
- 清晰的预览功能
- 支持下载生成的 Markdown 文件
- 包含示例 HTML 供快速测试
- 简洁现代的用户界面

## 技术栈

- Nuxt 3
- Vue 3 组合式 API
- TurndownJS (HTML 到 Markdown 转换库)
- Marked (Markdown 渲染)
- Tailwind CSS (样式)

## 安装

确保安装依赖项:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## 开发服务器

在 `http://localhost:3000` 启动开发服务器:

```bash
# npm
npm run dev

# pnpm
pnpm dev

# yarn
yarn dev

# bun
bun run dev
```

## 生产构建

构建用于生产的应用程序:

```bash

yarn build

# bun
```
